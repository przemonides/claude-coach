Add your profile

No accounts. To join the directory you open a PR adding yourself to docs/profiles.json. Easiest way: ask your own Claude Code to draft a profile for you — it knows you better than this form does.

1 · Ask your Claude

Copy the prompt below and paste it into a Claude Code session that's running in your project. It will interview you, refuse to leak sensitive info, and produce a JSON profile.

3 · Open a pull request

    

      We'll copy your JSON snippet to the clipboard and open
      docs/profiles.json in GitHub's editor. Paste your entry into the
      array (before the closing ], with a leading comma), commit on a
      new branch, and open the PR.
    

    

      
      
    


    

      Reminder: profiles.json is public. Don't include anything you
      wouldn't put on a personal site. Use a public contact channel (GitHub handle,
      public email, social link) — never an internal email or anything tied to a
      client.
